# 账户素材文件协议 v1

这是 [外观契约](APPEARANCE_CONTRACT.md) 的后端文件边界。实现由 #202 跟踪；当前在线协议仍为 v4，
本文不表示上传路由、文件安装或带字节备份已经启用，不授权修改实际部署数据。

当前实现批次仅提供 `src/storage/asset_files.py` 的阻塞文件适配器：发布、读取、显式作用域的日志遍历及
指定操作收尾。它没有认证、启动恢复编排、就绪事务、配置入口或备份接线；后续能力接入前仍不可上线。
`asset_io.py` 另提供未接入启动生命周期的独立工作池；实际服务接线必须使用同一池，不得每请求创建一个池。

## 身份与目录

数据库是归属、不可变描述、配额及 ready 的权威；磁盘文件或安装日志不能授予账户权限。
账户来自重新核验的认证主体，目录使用数据库中的账户公开 UUID，不使用可在逻辑导入时重分配的整数主键。
字节以本账户 SHA-256 寻址，合法同 hash 内容不可变。不同账户即使 hash 相同也使用独立命名空间。

配置的非根绝对目录是受信任的部署输入，必须预先创建，其内布局固定为：

```text
<asset-root>/accounts/<canonical-account-uuid>/blobs/
    <lowercase-sha256>
    .install-<operation-uuid>.json
    .install-<operation-uuid>.part
    .install-<operation-uuid>.json.tmp
```

所有可变路径段均独立验证为规范小写 UUID 或完整 64 位十六进制 hash；不接受 name、asset_id、URL、
用户给定文件名或 archive 内路径作为磁盘路径。操作 UUID 由服务器生成，暂存文件排他创建。
目录权限新建为 0700、文件 0600；不静默修改既有部署目录权限。读取不创建目录。

文件适配器针对受支持的 POSIX 部署：持有目录描述符，逐级拒绝符号链接，最终文件必须是普通文件；
所有读取、发布、清理使用这些句柄下的已验证名称，不先检查路径再重新打开另一份来源。
不支持所需目录句柄/同目录硬链接/原子 rename/fsync 的平台或文件系统须明确失败，不能退化成 copy/delete 并声称同等持久性。
这是应用管理目录的边界，不承诺抵御拥有服务器进程/文件权限的管理员恶意修改。

## 校验与安装状态

PNG 使用 `png-v1`，SVG 使用 `svg-v1`，分别对应现有 PNG/SVG profile；原 hash 和原字节不改写。
已安装元数据须记录所用 profile，未知版本不能按当前解析器盲目接受。增加或改变解析能力须显式评审版本兼容性。

Alembic `000000000005` 为 blob 增加 `validation_profile`：pending 的时间/profile 都为空，ready 必须
同时带已知且匹配媒体类型的 profile，数据库 CHECK 和读取边界同时验证。不重建 blob 父表或改变其主键/FK；
增量升级遇到历史无版本 ready 行时停止，不虚构其已通过验证；存在已安装状态时禁止丢弃该字段降级。
线上仍未启用安装，备份检查仍拒绝 ready 行，直到包含字节的完整备份路径接好。

| 阶段 | 持久事实 | 失败/重启后的行为 |
|---|---|---|
| 已声明 | 本账户 blob 描述与预留配额，ready 为空 | 原身份重试，不产生第二份额度 |
| 已验证输入 | 有界 EOF、长度/hash、完整格式/解码在内存验证 | 未成功验证不得创建安装日志或发布文件 |
| 已准备 | 规范安装日志已 fsync 并发布，目录已 fsync | 不能据日志自动把数据库改为 ready |
| 已发布文件 | 独立暂存完整写入、同句柄回读 hash、文件 fsync、同目录 rename、目录 fsync | 数据库未提交时仍为 pending，原身份可重试 |
| 已提交就绪 | 短事务重验认证/声明后提交 ready 与 profile | 回应丢失后重试仍校验实际请求字节并返回同一 blob |
| 已收尾 | 删除该操作的日志与残留暂存，目录 fsync | 收尾失败不撤销已提交事实；保留日志供恢复并报告故障 |

输入的网络读取、解码和文件 I/O 不持有 SQLite 写事务。初始授权、文件阶段和最终授权提交相互分开；
最终检查不能复用第一次查询的过期 User 对象，须验证账户状态、凭据版本/撤销状态、设备能力、服务器/epoch
和本账户不可变描述。恢复线程不持有客户端凭据，不能替一个已失效请求补做业务授权。

共享 `authenticate_header` 允许初始阶段只读核验 JWT/API Token，不更新 token 的 `last_used_at`；
原有路由默认仍在自己的请求事务内记录使用。文件阶段后的认证必须使用新会话重新查询，不得复用旧 User。

写入必须处理短写和零进度；校验与磁盘错误不能返回成功收据。每次都创建新的暂存文件，不原地改写现有 blob。
同 hash 的合法重试只会发布相同内容；失败不会覆盖其他 hash 或其他账户。同步阻塞 I/O 放在有界工作池，
取消网络请求不等于终止已经启动的文件线程；工作池容量必须保留至实际 I/O 完成，取消后不得继续提交 ready。
首次上线不提供分块续传或泛化 GC，单 blob 仍受 512 KiB/2 MiB 限制。

工作池属于单一事件循环，固定 1..8 个名额（缺省 2），不积压额外提交队列；满载直接返回内部 busy，
上层未来映射为可重试失败，未准入不得消费请求输入。任务在独立线程执行并复制调用上下文，
名额只由实际线程 Future 完成后归还，不能由已取消的请求协程归还；迟到结果不触发数据库提交。
请求取消会传播，后续线程失败仍被观察，不形成无人领取异常。线程内只允许文件与解码操作。
退出先停止准入、等待实际文件任务结束，再关闭数据库/存储依赖；退出等待被取消后保持禁止准入，
生命周期拥有者可重复等待完成。池不声称能强制中断挂起的内核/NAS I/O；请求体、流的关闭和读取期限
仍归传输适配器，不能在仍使用来源的线程结束前关闭来源，也不能把排空池当作单请求成功。

安装日志是规范 UTF-8 JSON，最大 8 KiB，包含格式版本、操作 UUID、账户公开 UUID、完整 blob 描述和 profile；
不记录密码、令牌或输入文件绝对路径。未知字段/版本、重复键、非规范身份、声明错配、日志与文件名错配均拒绝。
先完整持久化日志再创建图片暂存；日志自身通过排他临时文件、同目录硬链接发布，再删除临时名字，
最后 fsync 目录。硬链接发布拒绝覆盖已有操作日志，即使出现 UUID 碰撞也保留旧证据。
已存在但字节损坏的最终文件不由普通重试覆盖，须报告并进入单独修复流程；有效重试仅发布相同内容。

## 读取与恢复

下载仍从本账户 asset_id/variant 查数据库，不提供绕过归属的全局 hash 接口。ready 仅为提示，返回字节前
必须从同一个已打开的普通文件受限读取并核对长度/hash/profile。pending 返回既定 pending 错误；
已 ready 的缺失/损坏文件为 unavailable，不伪装为未上传或空图片，也不自动清除数据库 ready 以掩盖损坏。

启动恢复在接收安装请求之前处理已登记日志。已提交且字节验证通过的操作可收尾；未提交的操作只清理
其匹配暂存/日志，保留已发布不可变文件供重试，绝不自动发布 ready。已提交但文件不一致时保留证据并报告。
损坏或无法证明归属的日志不驱动文件发布或删除；未知文件不由扫描器猜测为垃圾。恢复可重复执行。
清理只作用于该操作明确拥有的文件，不递归删除账户目录，不删除未引用的最终 hash 文件。

## 备份与数据库提交边界

从一致数据库快照列出 ready 引用，再读取、校验、保存其全部原字节。首版不回收不可变最终文件，
因此快照中已提交引用对应的文件不会被后台 GC 撤掉；并发新增安装不必进入较早快照。
pending 元数据可以备份，但不虚构图片。缺失/损坏/未知 profile 均拒绝完整备份，不能仅交付成功的数据库文件。

恢复时先验证完整备份，再将所需不可变字节持久化到本账户命名空间，最后由现有数据库恢复/导入事务发布引用。
同 hash 文件内容相同，其他旧文件不改动；失败时原数据库仍指向其原文件，新添但未引用的文件保留且报告，
不据不完整事务删除旧数据。这样无需额外的整套文件代次切换协议；文件发布和数据库提交仍不是一个原子操作。
原有安全备份、停止写入、计时处理、实例身份和 epoch 规则继续执行，不降低恢复门槛。

物理/逻辑备份格式显式版本化，记录 profile 和 blob 描述；逻辑导入按账户公开身份还原文件归属，
不能使用导入后的整数主键去猜旧文件位置。旧无素材归档继续按其版本验证；不能手工修改版本号假装兼容。
实际 NAS、权限与断电持久性必须另行验收；本机临时文件故障注入及 CI 不等同于 NAS 断电实验。

底层语义依据：[Python fsync](https://docs.python.org/3.12/library/os.html#os.fsync)、
[硬链接与目录句柄](https://docs.python.org/3.12/library/os.html#os.link)、
[同文件系统原子替换及目录句柄](https://docs.python.org/3.12/library/os.html#os.replace)。
