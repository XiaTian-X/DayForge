## 完成标准

- 历史 `src/test` 中的 Android 测试逐项审查并迁入真机；保留有效断言，弱测试用实际行为检查补强。
- 不保留恒真占位、吞异常、跳过用例或测试内部生成待验证预期的自证路径。
- 预期有独立依据；高风险边界用错误实现检出证据校验。测试总数和覆盖率不能单独证明正确。
- 最终真机完整套件、后端与仓库检查通过；生产变更按各自风险补对应检查，并经 PR 合并。
- 当前设备无法覆盖的其他 API / 厂商设备、断电、NAS / 外网及真实服务器联合验收明确记录为未验证，不能写成通过。
