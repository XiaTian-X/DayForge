# 主题存储前置整改（#180）

## 范围与规划审查

关联 #160 外观与一次性事项重构。本批只修复现有主题文件仓库，不启用新主题/图标格式、
不改变卡片布局、颜色算法、事项生命周期、数据库或同步协议。

规划的修正与阶段安排记录在 #160。用户已确认事项完成后保留且可撤销、配置导入使用新身份
且不恢复完成历史；不要求保留当前测试数据。实际新基线切换须另行限定重置范围，
不能据此删除当前手机/后端数据、改写冻结请求或自动清库。本批没有执行任何重置。

## 已处理

- 主题 ID 拒绝空白、路径分隔符、控制字符、点目录和超出文件名预算的 UTF-8 内容；
  保留普通 Unicode 名称。文件路径相对于系统 filesDir 的可信规范路径，拒绝主题目录、
  文件的符号链接（包括悬空链接），并验证 JSON 身份与文件名一致。
- 仓库读写进入 IO 调度器，同一进程的多个仓库实例共享互斥锁。
- 新文件先写入同目录唯一临时文件并刷新，再使用原子移动发布；不回退为非原子复制。
  重复添加不覆盖，提交前异常清理暂存，进程中断遗留的 `.tmp` 不作为主题加载。
- 删除失败如实返回；取消继续传播。存储层不记录导入 JSON、名称或任意异常消息。
- 文件读取和序列化后的写入上限为 1 MiB，ID 上限为 240 UTF-8 字节。
  该限制不是整个导入链路的安全声明：文件选择入口的有界读取在素材导入专项完成。

## 测试边界

`CustomThemeRepositoryTest` 使用隔离测试包 cacheDir 下唯一临时目录，真实文件系统与
IO 调度器；退出不跟随测试符号链接。覆盖正常 Unicode 文件往返、原 JSON 导出、删除、
路径穿越、文件与目录符号链接、悬空链接、并发重复添加、损坏/超大/身份不匹配文件、
未发布临时文件、提交前故障清理与重试、取消。

原子发布故障在路径复检处注入，验证已经写入暂存的内容不会成为 live 文件；
这不是设备断电、存储硬件故障或磁盘耗尽的真实演练，也不承诺跨进程互斥。
应用目前单进程；未来多进程写入须重新设计锁与发布策略。
