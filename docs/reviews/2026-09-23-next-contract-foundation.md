# #181 首批契约审查与验证

## 范围与结论

本批固化 D-011、一次性事项纯转换及图标引用/包元数据，并让 Android 与后端消费同一份正反例。
现有 UI、Room、Alembic、v4 路由、OpenAPI、依赖锁文件和计时状态机未改变。
前置主题存储修复 #180 已通过 PR #182 合并，本批不重复其改动。

`#181` **未完成**：完整主题角色、配置包具体字段与协议外壳仍需后续冻结；
账户授权、数据库 CAS、pull/bootstrap、资源解码/安全安装、配置恢复和小组件适配尚未接入。
本文不能作为一次性事项或素材导入功能已上线的证明。

## 关键审查

- 事项与图标解耦；完成全局有效，撤销必须针对当前完成事实，不依赖“今天”。
- version 与因果 head 同时匹配，避免两个离线分支具有同数字版本时互相覆盖。
- 完成/撤销/再次完成保留独立事件身份；幂等重放属于调用方，不由纯 reducer 猜测。
- 删除优先、版本上限、错误码、非法投影与请求均有约束；纯函数不修改输入。
- 角色引用与固定素材引用区分，任务用途不可混入普通角色；元数据缺失不当作授权成功。
- 字节/像素/数量/总量边界、重复身份、同 hash 元数据矛盾和未知字段拒绝；
  Android 整数序列化器明确拒绝数值字符串、布尔值、小数及溢出，避免跨端隐式转换差异。
- 包样例只是合成元数据，不含真实图片；通过元数据模型不等于图片、安全 ZIP 或账户校验通过。
- 原有 v4 fixtures 和线上 DTO 不改变，`contracts/next` 明确标识未启用。
- 配置包不沿用跨账户 UUID；暂存、身份映射、替换确认、本地原子与远端部分成功分别定义。
- 不自动清除测试数据，不改写已合并迁移或冻结请求，实际重建待用户确认具体范围。
