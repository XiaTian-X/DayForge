# 新结构同步审查（#191 第四批）

## 范围与边界

沿用既有调用方事务、逐操作保存点、结构 revision、不可变 snapshot/change 和操作幂等记录，
内部 next_protocol 路径接入 NextPlanNode/NextMetric 与显式外观。原 one_time_events 内部开关
随范围扩展重命名，既有事实回归仅更新参数名，未删除断言。生产路由不接受/开启此参数。
没有修改 v4 OpenAPI、注册或 advertised/minimum 版本，也未挂载测试占位路由。

新建事项原子初始化 0/null/null，普通习惯保持 null 投影。有事实（包括墓碑）或任意计时会话
后拒绝完成策略转换；无历史的合法转换与外观用途校验同事务处理。完成/撤销不修改结构 revision，
名称、图标和目标归属编辑不改变事项状态。没有把计时变成普通手工结果接口。

外观继续使用账户复合外键；快照不含旧 icon/color，不在同一 revision 拼入动态完成投影。
三方合并原子处理 icon 引用，允许非重叠强调色变化，冲突携带原始 base/权威 entity。
目标删除沿用 cascade/detach，子项 change 保留准确外观；完成历史和删除对象明细不清除。

bootstrap 在原会话事务中读取外观、完整历史和检查点，与游标使用同一快照。缺失末尾历史、
缺失/损坏外观失败，不返回默认数据或推进成功游标。检查点只含当前账户可见事项。
普通计时、指标和关联序列化仍保持原语义；新 pull 校验事项事实的不可变证明。

## 验证

新增 42 项定向回归通过：全部基础模式/正倒、完成后编辑/跨日撤销、显式无历史转换、
事实/计时历史锁定、跨账户与错误用途、每项拒绝不阻断独立有效操作、role→asset 合并、
重放原快照、目标两种删除策略、事实设备权限、内部故障回滚与原拒绝重放。

测试专用 HTTP bridge 使用真实 JWT/API Token 和生产 get_session；验证 COMMIT 延迟外键失败、
响应模型失败、幂等结果/游标失败均整批回滚（含认证元数据），原操作身份可重试。
真实两个 SQLite 连接竞争中，另一请求完成事项后旧结构写/恢复请求返回 DATABASE_BUSY，
零部分写入，原请求重试可见完整状态。不是仅模拟异常或提高超时来取得通过。

既有事实/结构/外观组合首轮 103 项通过。最终锁定环境全量通过：1,377 项后端测试，
296.18 秒、1 项既有 warning；mypy 156 个文件、Ruff 与 OpenAPI 门禁通过；仓库检查 22 项。

由上述测试专用 HTTP bridge 覆盖，不能表述为已经部署的 v5 TCP 接口验收。
