# #181 主题与配置元数据契约审查

## 范围与结论

接续 PR #183，本批落实完整主题色板与配置包 v2 的双端模型、共享样例和校验。
不改变当前 v4 API、Room/Alembic、UI、计时状态机、旧配置导入入口或依赖版本。
`#181` 尚需同步外壳及事项投影传输契约；本批不关闭 #181 或 #160。

## 重点审查

- 主题每套色板固定 36 Material、12 状态和 4 图表角色；浅深两套均完整。
  缺项/未知项/非法颜色拒绝，不补库默认值。种子与生成器仅作来源，未知生成器也不执行。
- 配置覆盖普通打卡、正倒计数、正倒计时、一次性事项、五类计划、目标、指标聚合/目标及关联。
  排除事实、事项完成、账户/服务端身份和 outbox；局部引用不能授权更新已有账户实体。
- 单父节点只允许顶层目标，拒绝无效端点、重复名称/身份/关联和无效用途图标。
  事项不能带计数/计时、周期目标或每日偏好；普通习惯不能使用事项角色/素材。
- 图标引用自带 `kind` 判别字段，计划使用 `type`，在同一默认 JSON 编解码器下可以嵌套往返。
- 缺图角色显式声明、保留引用；内嵌包不自动替换设备当前包，不悄悄转成固定素材。
- 对象色保留 RGB/ARGB，主题色为不透明 RGB；不延续旧七位颜色误接受。
- 实测发现 Android 默认接受字符串布尔值；新增严格布尔/数值/字符串序列化器，
  两端共同拒绝字符串数字、数字名称、引号布尔值及无穷值。共享基础值校验避免规则漂移。
- 空配置须全部字段显式提供，缺字段不能成为清空指令；数量与字节预算分别定义。

这些合成清单不含真实 SVG/PNG，不能作为可安装 ZIP。真实字节安全验证、重复 JSON 键、
压缩/深度限额、暂存安装、导入身份映射/事务/恢复、账户素材授权传输和界面解析尚未接入。
完整色板通过格式校验不等于实际显示对比度达标，显示适配另有门槛。
配置字段保留不代表现有 Android 已持久化全部未来字段，不得改变目标窗口的原语义。

使用隔离 testbed，不覆盖正式 App；不清手机/后端数据，不执行 Docker、NAS、外网或人工 UI 验收。
