## 仍需分别验收

- 同一账户两台实物安装、主设备与离线/重放的完整九阶段，包括原六条 ACK 见证、服务器终态和两端清理。
- 当前完整普通与专用配置的发现、完整类结果、去重归属、真实进程终止及副本恢复组，按各自准入与阶段执行；单机 Q04C 的完整链不覆盖其它进程故障点。
- 实际 Launcher、系统 Worker、近发布可见交互、自然连续操作与积压收敛、输入后首帧和下一次可操作时点。旧性能超标及局部结果保留；debug 覆盖率运行不能替代实际交互验收。
- NAS/外网仍缺隔离环境。实际 USB 回环后端只覆盖其声明的网络范围。最终提交的 CI、发布范围和 PR 尚需以实际终态核对。
