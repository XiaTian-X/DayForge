# 素材声明事务与冻结目录审查（#191 第二批）

## 范围与结论

在第一批五表和恢复校验基础上接入实际声明/读取服务，不挂载生产路由，不改变 v4。
账户只从认证主体取得；有效设备、结构写权限、服务器身份和 epoch 均在访问素材前验证。
读取不创建账户 quota/policy，不触碰设备 last_seen，避免把目录读取误变成写锁操作。
JWT/API Token 认证依赖本身沿用既有行为，未来图片流式传输仍必须另行拆开短认证事务。

素材和包版本不可变，内容相同重放不重复预留或追加目录；同 ID 异内容和相同 hash 异描述拒绝。
blob 在账户内去重，包括 light/dark 同 hash。包的每个素材必须已在本账户完整声明。
条件 UPDATE 原子预留字节/数量/规范 UTF-8 元数据和目录序号，所有新增行由调用方同事务提交。
限额下降后既有内容可原样重放，仅增加元数据的包不再增加字节或素材计费。

目录使用独立序列并冻结 through，在一致快照中分页；拒绝错误边界、账户越界和缺失条目。
不读取/推进业务 sync cursor，不把可变 ready 状态放进不可变目录。
两个真实 SQLite 连接竞争的落败事务必须整体回滚后再以原身份重试，不能在过期快照内自旋。

## 验证边界

自动化覆盖账户/设备/能力/epoch、跨账户同 ID/hash、重复及修改声明、包依赖、精确额度边界、
UTF-8 计费、降低限额、目录序号耗尽、写入阶段注入失败、两连接初次创建 quota/已有 quota 竞争，
以及固定高水位分页、重复页面、边读边追加、缺口拒绝和无副作用的空目录/默认额度读取。
额外覆盖损坏 JSON、声明身份/计费不符和 SQLite 非整数额度/序号的稳定拒绝；测试快照直接读取
原始数据库行，不用模型序列化掩盖故意注入的非法类型，也不放宽警告预算。

测试专用 FastAPI bridge 使用真实 JWT/API Token 和生产 get_session（没有覆盖会话依赖）：
验证数据库 COMMIT 延迟外键失败、目录插入失败和响应校验失败后整笔回滚，原身份重试与重放。
独立连接在成功响应后核对持久状态；这不是生产 v5 协商、图像上传或部署验收。

新增 77 项定向用例连同警告门禁通过，保留 1 项已登记开发环境警告。

警告预算和 OpenAPI 一致性全部通过。`./tools/verify root`：22 项通过。
