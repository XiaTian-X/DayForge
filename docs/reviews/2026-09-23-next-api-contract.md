# #160 / #181 前向同步与素材 API 审查

## 范围

当前运行协议仍为 v4。本批定义 v5 外壳、显式事项策略、对象外观、独立事项拒绝上下文、
bootstrap 校验点以及素材声明/收据/目录/配额值；没有新增在线路由、迁移、文件安装、账户授权实现或 UI。
未来增量 OpenAPI 明确 NOT ACTIVE，不通过空 handler 冒充可用 API。当前 OpenAPI 保持不变。

既有结构业务字段提取为 PlanNodeCore / MetricCore，新旧外观分别扩展；配置与同步共用
ObjectAppearance，避免两份字段规则漂移。v4 仍拒绝新字段，原规范 JSON/操作指纹用例保留。
Android 新字段验证不取代完整业务 mapper，更不证明响应来自已认证账户。

## 审查中修正

- 不将显式 null 目标当成默认 1；拒绝字符串/空值倒数标记与客户端提交只读完成投影。
- 请求外壳保留逐项批量语义，领域校验单独在操作层执行；不能让一个坏载荷使合法同批操作全部 422。
- 拒绝结果不能带伪造事件、revision 或结构冲突快照；结果绑定原 operation/entity/activity。
- 成功结果还须提供与原请求完全一致的事项 intent 及正确 activity 的不可变证明；仅外层 ID 一致不够。
  拒绝无证明、别的事项、另一个合法但不同的意图，以及成功状态带错误码。
- bootstrap 校验全部可见事项的唯一 checkpoint 和从初始状态起的完整历史，拒绝缺尾、缺全部历史、
  重复实体、墓碑和普通习惯携带事项证明。pull 允许事实先于父对象到达，仓库负责延迟依赖和原子合并。
- 素材/包响应绑定完整不可变元数据、设备、服务器与 epoch；上传收据绑定 asset/variant/hash/长度/尺寸。
  目录有冻结高水位与严格递增序号，支持完整 64 位范围，拒绝浮点/字符串/越界游标。
- 限额降低后允许读出超额的原预留量，不能将其误认为非法响应或删除旧素材。
