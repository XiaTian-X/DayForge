# 账户素材存储与恢复审查（#191 第一批）

## 范围

为 #160 / #191 建立持久化与恢复基础，不启用 v5，不创建上传或声明占位接口。
Android、已确认 UI、现有 v4 请求/响应和计时逻辑不变；没有操作已部署数据库或正式手机应用。

增量 Alembic `000000000003` 新增五表：账户额度、blob 描述、不可变素材、包版本、独立目录。
通过复合外键绑定 owner 与目标主键；UUID、hash 和包版本均按账户限定。
额度使用 64 位存储，允许管理员降低限额后现有预留高于限额。此批没有提供管理员额度修改 API。
迁移不创建账户配置或转换旧数据，降级遇到任意新配置/素材即停止；SQLite DDL 失败整笔回滚。

## 审查结论与防护

- 原逻辑归档以 `next(column.foreign_keys)` 选取引用，对复合所有权外键可能选错。
  现明确选择单列主身份；模糊或不支持的引用拒绝。不是关闭外键或放宽账户限制。
- 归档以账户公共身份定位 quota/blob/asset/pack/catalog，包键包含 revision。
  恢复可重新分配内部主键，不混淆两个账户同名 UUID/hash 或同一包多个版本。
- 物理检查、逻辑导出和事务内导入共用完整元数据验证；核对规范 JSON、UTF-8 计费、
  blob 描述、账户内包引用、完整连续目录及去重预留量。校验和正确不等于业务数据正确。
- 校验在调用方同一快照内读取；失败导入不保留部分行、服务器身份或新 epoch。
- 本阶段没有字节安装能力。任何 `ready_at` 非空的备份/恢复明确失败，避免数据库单独恢复
  被误报为图片完整恢复；后续闭包实现必须替换此显式门禁并补全缺图/损坏/中断验证。
- SQL CHECK 不保证 SQLite 动态类型的整数性或全部元数据语义，严格类型与完整图验证仍必要。
  此批不是声明并发、额度原子预留、真实上传/解码或 v5 HTTP 授权的验证证据。

## 自动化验证

新增 4 项归档主身份解析测试和 38 项素材存储/恢复测试，覆盖迁移保留、DDL 失败重试、
空额度降级拒绝、跨账户 light/dark/目录引用、删除被引用记录、范围及唯一性约束、
两账户相同 ID/hash 与两包版本恢复、降低配额、篡改后重算 checksum、整笔失败回滚与合法重试。
另覆盖源数据计费/目录/blob 不一致和未支持 ready 字节的导出拒绝，检查临时文件清理及源库保持。

本地最终 `./tools/verify backend`：1231 项通过，262.47 秒；冻结环境、Ruff 检查/格式、
mypy（141 个 Python 文件）、警告预算与 OpenAPI 一致性均通过，保留 1 项已登记警告。
`./tools/verify root`：22 项通过。独立临时 TCP 服务完成登录、设备注册、全部实体 push、
计时命令、bootstrap、原身份幂等重放、物理备份/恢复及重启再读/重放；没有使用现有部署数据。
交付仍需 PR 的 repository/backend 与 amd64/arm64 容器 CI 全部通过；本地结果不代替 CI。
本批不涉及 Android 源码或共享 wire fixtures，因此未重跑真机测试；未执行本地 Docker、NAS、
外网或人工 UI 验收。CI 容器构建与恢复仍须独立通过，不能代替 NAS 验收。
